# Method: destruction before redesign

The Extractor operationalizes one principle: **subtraction is a reasoning process, not a minimalist aesthetic.**

The workflow uses the owner's Art of Reduction sequence:

- **R0 Source** — freeze the complete original and constraints.
- **R1 Essential** — remove duplication, filler and unrelated detail.
- **R2 Human** — rewrite only what survived, preserving facts and voice.
- **R3 Composed** — organize around one dominant human task and clear next action.
- **R4 Minimum useful** — keep removing until another subtraction would damage meaning, trust, identity, accessibility or task completion.

## The six questions

Every element must earn its place by doing at least one job:

1. Add a fact.
2. Help a decision.
3. Establish trust.
4. Express real identity.
5. Enable an action.
6. Prevent an error.

If it does none of these, deletion is the default proposal.

## Why deletion comes before rewriting

A normal “humanizer” sees weak copy and generates different copy. The Extractor first removes the weak copy, inspects what information is now missing, and only then decides whether replacement content is needed.

That prevents this failure loop:

`generic headline → different generic headline`

and replaces it with:

`generic headline → delete → inspect information gap → add only what the human needs`

## What The Extractor is not

- Not a promise that minimal pages convert better.
- Not an authorship detector.
- Not a universal visual style.
- Not a reason to remove legal, medical, accessibility or safety details.
- Not a substitute for user research, analytics or subject-matter review.

## Provenance

Automated AI-text detection is not reliable enough to establish authorship across models, domains and edited text. The Extractor reports observable signals and provenance separately. It uses `origin unknown` unless authorship is independently established.

## Brownfield rule

For an existing website or product, record baseline screenshots, content, behavior and tests before changing it. Preserve rollback. The first deliverable is the audit, not the rewrite.
