01 / POSITION

Not a humanizer.
A removal system.

Most tools see weak AI-shaped language and write different language. The Extractor first asks whether the element needs to exist.

  1. 01Freeze the original.
  2. 02Define the human job.
  3. 03Label what is empty.
  4. 04Delete before replacing.
  5. 05Humanize what survives.
  6. 06Stop before subtraction harms the user.

02 / METHOD

R0 → R4

Reduction is not minimalism. The stopping point is where another deletion would damage meaning, trust, identity, accessibility or task completion.

R0

Source

Freeze the current state. Facts and constraints become immutable reference.

R1

Essential

Remove duplication, filler and unrelated detail.

R2

Human

Rewrite only what survived. Protect voice and evidence.

R3

Composed

One dominant human task. Visible hierarchy. Obvious next action.

R4

Minimum useful

Remove one more thing at a time. Stop before the experience gets worse.
